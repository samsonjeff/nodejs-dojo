# nodejs-dojo

A structured documentation of my Node.js learning path. This repository serves as a beginner-friendly guide for anyone who wants to learn Node.js from the ground up.

**Repository:** https://github.com/samsonjeff/nodejs-dojo

## About This Repository

This repository contains all the concepts, examples, and exercises I learn throughout my Node.js journey. Once completed, all modules will be integrated and executable via `app.js`, allowing anyone to see the output and learn from the code.

Each module includes its own guide and reference information explaining where the concept comes from, making it easier to understand and learn individually.

> **Note:** This repository is intended for beginners who are just starting with Node.js. Please do not expect advanced topics.

## Who Is This For?

- Beginners who want to learn Node.js
- Anyone looking for a simple, hands-on guide to Node.js fundamentals
- Developers who want to review core Node.js concepts with practical examples

## What You'll Find Inside

- Core Node.js fundamentals
- Modular examples with clear explanations
- Well-commented code for easy learning
- Source references for each module
